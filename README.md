# Лабораторная работа: Стек и Очередь
## Задача №3: Реализация очереди через два стека
---
### Описание задачи

Целью работы является реализация структуры данных очередь (FIFO - First In, First Out) с использованием двух стеков (LIFO - Last In, First Out).

### Алгоритм решения
Использование двух стеков позволяет имитировать поведение очереди:

    in_stack: Служит для приема новых элементов (операция enqueue).

    out_stack: Используется для извлечения элементов (операции dequeue и front).

Когда out_stack пуст, все элементы из in_stack перекладываются в него. При этом порядок элементов инвертируется, и самый "старый" элемент оказывается на вершине второго стека, что и обеспечивает логику очереди.
### Реализация

В ходе работы были реализованы следующие методы:

    enqueue(x) - добавление элемента в конец очереди. Сложность: O(1).

    dequeue() - удаление и возврат первого элемента. Сложность:  O(1) для кажого элемента, а так в общем O(n).

    front() - получение первого элемента без удаления. Сложность: O(1) для кажого элемента, а так в общем O(n).
    
    size() - получение текущего количества элементов в очереди.
### Пример использования
```python

q = Queue()
q.enqueue(1)
q.enqueue(2)
q.enqueue(3)
q.enqueue(4)
print(q.dequeue()) 
print(q.front())   
print(q.size())
```
